Workshop checklist

Print this, annotate it, and keep it beside the iPod. It is a preparation aid; the model-specific procedure still controls the work.

Before ordering

  • Identify the exact iPod and original capacity.
  • Choose one build outcome.
  • Confirm adapter, battery, and rear-case compatibility together.
  • Save direct sources and return information.

Before opening

  • Back up data if possible.
  • Photograph exterior and existing faults.
  • Inspect battery; stop if damaged or swollen.
  • Read the entire procedure and opening reference.
  • Set out tools, display protection, and parts tray.

Before closing

  • Restore or initialise successfully.
  • Verify storage recognition and a small transfer.
  • Test charging, audio, wheel, display, and hold switch.
  • Check every flex cable has a smooth, unpinched route.
  • Confirm case closes with no force, rocking, or gap.

After closing

  • Perform a longer sync and playback test.
  • Record exact build parts, firmware, and date.
  • Keep source links and photos with the build record.
  • Contribute a verified result when ready.
