Evidence registry

Tested builds

This registry separates an appealing idea from a documented result. A configuration is not “working” here until its exact variables and test outcome are recorded.

Current status: registry ready; no publish-level entries yet

That is intentional. The existing 7th-generation storage procedure is a clearly labelled draft that still needs bench validation and original photos. This page will not convert community anecdotes into guarantees.

Record format

What a trustworthy entry contains

Exact variables make a result reusable and make failures diagnosable.

FieldRequired record
iPodApple name, original capacity, firmware, rear-case depth, and condition.
PartsAdapter brand/revision, storage make/model/capacity, battery seller and measured dimensions, rear case, and any connectivity hardware.
MethodPreparation, restore computer/operating system, procedure revision, and changes from the documented guide.
VerificationOpen-case restore, charging, controls, audio, transfer/playback test, duration, and result.
EvidenceDated photographs of connector routing, fitment, restore result, and finished build; direct sources; known limits.

Contribution standard

Contributors can use the procedure template and the project’s contribution guide. State what was tested, what was not tested, and whether an item was supplied or purchased.

Badges for future entries

Bench-tested exact setup verified by the guide maintainer. Community report configuration reported with sufficient detail but not independently reproduced. Deprecated known incompatibility or outdated method, preserved with a reason.
