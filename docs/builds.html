Recipe rule: one new variable at a time

Install and test storage before changing the battery. Test battery fitment before adding connectivity hardware. This sequence prevents a difficult reopening from becoming a multi-fault diagnosis.

Before purchasing

  • Confirm exact iPod model and original capacity.
  • Record adapter revision and media specification.
  • Measure received battery and rear-case depth.
  • Retain a return path for untested parts.
